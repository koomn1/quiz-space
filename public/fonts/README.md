# Board fonts

- **Molhim-Bold.ttf** — Molhim Bold, main board writing font. Free font by its designer
  (source page: https://arfonts.net/molhim-bold-font). The foundry note asks that the font
  not be edited or redistributed without the designer's approval; bundled here with the
  site owner's acceptance of that note (Youssef, Nov 28 2026). Do not modify the file.
- **ArefRuqaa-Regular.ttf / ArefRuqaa-Bold.ttf** — Aref Ruqaa (Ruqaa script), board headings
  and important points. SIL Open Font License 1.1, from google/fonts:
  https://github.com/google/fonts/tree/main/ofl/arefruqaa
